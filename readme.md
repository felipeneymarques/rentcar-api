## Objetivo e Nome 
Locadora de Carro -> Alugar automóveis para o público
Nome -> Faster and Furious Rent Car

## Caso de Uso
- Cadastro do Veículo
- Cadastro do Condutor
- Processo de aluguel e devolução

Cadastro do Veículo: usuário cadastra o veículo usando marca, ano, modelo, cor e placa.

Cadastro do Condutor: usuário cadastra o condutor usando nome, data de nascimento, CNH, CPF e gênero

Processo de aluguel: usuário relaciona veículo ao condutor, data de aluguel, data de devolução, quantidade de combustível na saída e quantidade de combustível de entrada

# Requisitos Técnicos 

- Backend em NodeJS + Express
- Frontend em React e Vite. (Feito com IA)
